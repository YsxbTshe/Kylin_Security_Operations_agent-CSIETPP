# 软件功能测试报告

> 数据采集时间：2026-08-15。安全决策基准通过 `mvn -B verify -Dbench.regenerate=true` 生成；真机验收环境为银河麒麟高级服务器操作系统 V11（aarch64）。本报告按测试环境、样本规模和证据来源限定结论适用范围。

## 1. 测试概述

### 1.1 测试目的

本报告验证系统安全智能运维核心功能的正确性与一致性，重点包括：

1. 安全意图校验：注入、越权、关闭安全机制等高风险意图能否由确定性规则拦截；
2. 高风险操作控制：R3/R4 操作能否稳定进入审批流程；
3. 审批令牌绑定：SM2-with-SM3 签名、字段覆盖复判和一次性消费规则能否识别篡改；
4. 分层治理有效性：风险分级、硬底线、意图一致性与审批令牌各层的作用；
5. 产品能力一致性：签名工具目录、十二步下发门禁、ReAct 运行时与计划门控的接口口径是否统一。

### 1.2 测试范围

| 测试层级 | 测试内容 | 证据形式 |
|---|---|---|
| 自动化安全决策测试 | `PolicyEngine.evaluate → IntentAlignmentGuard.align`、审批判定、SM2-with-SM3 令牌验签与覆盖复判 | JUnit 集成测试与自动生成 Benchmark 报告 |
| 自动化架构对照 | 逐层启用风险分级、硬底线、意图护栏和令牌绑定 | `AgentArchitectureBenchmarkIT` |

| 真机验收 | 节点注册、gRPC mTLS 控制流、工具下发、审批闭环、特权执行、主机安全姿态采集 | 银河麒麟 V11（aarch64）环境日志与演示记录 |

自动化统计针对安全决策层；真机执行链路按独立验收证据评审，两类证据不混合计算通过率。

## 3. 测试方法与判定规则

### 3.1 判定口径

- 恶意意图：判定为 `denied` 且风险等级为 R5；
- 良性意图：判定为非 `denied`；
- 风险升级：敏感路径或主机安全姿态使风险达到预期等级；
- 审批门禁：R3/R4 动作进入人工审批，不直接执行；
- 令牌安全：claim 篡改、未知密钥签名、过期令牌、格式错误和参数摘要失配均被拒绝；
- 合法令牌：在有效期、身份字段和风险上限匹配时通过验签与覆盖复判。

### 3.2 审批令牌绑定口径

审批令牌采用 **SM2-with-SM3**。签名覆盖 `ApprovalClaim` 的全部 **17 个字段**；特权执行侧对其中 **13 个身份字段**逐字段复判：

`tenant_id / run_id / agent_instance_id / agent_invocation_id / tool_invocation_id / execution_attempt_id / node_id / tool_id / tool_version / arguments_sm3 / risk_ceiling / execution_mode / lock_version`

其中风险等级须不高于审批上限，其余字段须精确一致。审批决策接口使用独立权限码 `agent:approve`，并执行发起人与审批人分离规则。

### 3.3 十二步下发门禁

每次工具调用依次经过以下确定性门禁：

1. 运行与调用身份完整性；
2. 授权范围与预算；
3. 策略风险分级及注入规则；
4. 意图一致性；
5. R5 强制拒绝；
6. 执行模式约束；
7. 工具维 ABAC；
8. 专家注册表能力封套；
9. 主机维 ABAC；
10. 主机安全姿态；
11. 工具风险与审批属性核对；
12. 审批判定。

门禁采用 default-deny；任一步拒绝即停止下发并记录结构化事件。

### 3.4 核心安全判据

| 判据 | 通过条件 |
|---|---|
| G1：R5 动作执行数 | 0 |
| G2：R3/R4 无有效审批执行数 | 0 |
| G3：宿主机通用命令通道 | 宿主机调用限定为签名工具与固定 argv；workspace 工具限定在隔离环境 |
| G4：审批令牌篡改接受数 | 0 |
| G5：运行事件链 | 事件按 SM3 前向哈希关系记录并可在线校验 |

## 4. 测试结果

### 4.1 安全门禁评测

测试类：`AgentSafetyBenchmarkIT`；采集日期：2026-08-15。

| 指标 | 结果 | 通过/样本 |
|---|---:|---:|
| 恶意意图拦截率 | **100.0%** | 20/20 |
| 良性意图放行率 | **100.0%** | 6/6 |
| 风险升级正确率 | **100.0%** | 3/3 |
| 审批门禁正确率 | **100.0%** | 3/3 |
| 审批令牌伪造拒绝率 | **100.0%** | 5/5 |
| 合法审批令牌验证 | **通过** | 1/1 |

决策延迟观测值：均值 **0.68 ms**、P50 **0.41 ms**、P95 **1.79 ms**，样本数 32。该组数据用于说明单机测试环境下确定性护栏的时延量级；跨机器或跨版本比较时应重新采样。

恶意意图分组结果：

| 攻击类型 | 结果 | 拦截/样本 | 主要判据 |
|---|---:|---:|---|
| Prompt 注入与禁止动作 | 100.0% | 8/8 | `POLICY_R5_FORBIDDEN_OR_INJECTION` |
| 关闭 Native Guard 或审计 | 100.0% | 6/6 | `POLICY_R5_NATIVE_GUARD_DISABLE` |
| 意图不一致与越权变更 | 100.0% | 6/6 | `POLICY_INTENT_MISMATCH` |

### 4.2 架构分层对照

| 对照层级 | 恶意拦截率 | 良性放行率 | 风险升级正确率 | 审批门禁正确率 | 令牌伪造拒绝率 | 决策延迟均值(ms) |

| A0 基线 | 0.0% | 100.0% | 0.0% | 0.0% | 0.0% | 0.00 |

### 5.2 结论

在本报告所列自动化用例中，安全意图、风险升级、审批门禁与审批令牌测试均达到预期；架构对照显示各治理层分别承担硬底线拦截、意图一致性和审批绑定职责。真机执行结论应结合银河麒麟 V11（aarch64）验收日志、任务时间线和演示记录评审。

## 6. 适用范围与方法学说明

### 6.1 样本与统计口径

安全决策样本包括恶意 20、良性 6、风险升级 3、审批门禁 3、令牌伪造 5。用例由项目测试集给出确定性期望，百分比为该封闭样本集的点估计。恶意用例中，14 条覆盖硬底线关键词，6 条覆盖不依赖该关键词的意图不一致场景；评审时可分别观察两组结果。

### 6.2 环境适用范围

- H2 内存路径用于自动化安全决策和迁移兼容测试；

- 银河麒麟 V11（aarch64）记录用于真机链路验收；
- 网络、外部模型和硬件负载会影响端到端时延，相关数值应在目标部署环境重新采集。
