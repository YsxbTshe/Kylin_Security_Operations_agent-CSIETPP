# 软件性能核心指标测试报告

> 数据来源：安全决策指标取 2026-08-15 单机基准执行；RAG 检索指标取 `bench/rag/results/results.json` 与 `docs/05-评估方案/RAG-Benchmark报告.md` 的基准产物。各项结果按对应测试环境、样本规模和依赖条件解释。

## 1. 概述与范围

### 1.1 测试目的

本报告量化系统核心性能与质量指标，为功能测试、部署验收和决赛指标表提供可追溯的数据依据，重点包括：

1. 确定性安全决策延迟；
2. RAG 混合检索时延与质量；
3. R5/Prompt 注入拦截率；
4. R3/R4 无审批执行数。

### 1.2 测试范围

| 指标域 | 本报告数据 | 适用范围 |
|---|---|---|
| 安全决策 | 均值、P50、P95、分层治理延迟 | H2 内存路径、单机确定性规则基准 |
| RAG 检索 | recall、precision、MRR、NDCG、MAP、P95 | 指定语料、查询集、远程 embedding 与 Elasticsearch 环境 |
| 安全硬指标 | R5 拦截率、R3/R4 无审批执行数 | 自动化决策用例集 |
| 真机运行 | 银河麒麟 V11（aarch64）执行链路 | 结合真机日志、任务时间线与演示记录评审 |

端到端时延、并发成功率、断线重连、回滚时延等运行指标受主机、网络和可观测栈配置影响，应在目标部署环境按统一脚本采集，不与本报告的决策微基准混合比较。

### 1.3 指标选取原则

1. 指标具有明确采集来源和样本口径；
2. 安全指标采用逐用例判定；
3. 时延指标优先报告 P95，同时保留均值和样本数；
4. PostgreSQL/pgvector 与 H2 内存路径按部署条件分别陈述；
5. 同一指标仅在环境、语料和配置一致时进行横向比较。

## 2. 核心指标结果

| # | 指标 | 目标 | 观测值 | 数据来源 | 结论 |
|---|---|---:|---:|---|---|
| P1 | 安全决策延迟（均值 / P95） | 低开销 | **0.68 ms / 1.79 ms**，32 次评估 | `AgentSafetyBenchmarkIT`，2026-08-15 | 亚毫秒到毫秒量级 |
| P2 | RAG 检索 P95（三通道） | < 800 ms | **287.6 ms** | `bench/rag/results/results.json` | 达到目标 |
| P3 | RAG recall@10（三通道） | 高于单路 | **0.761** | 同上 | 高于该基准中的各单路结果 |
| S1 | R5 / Prompt 注入拦截率 | 100% | **100%（20/20）** | `AgentSafetyBenchmarkIT` | 达到用例集目标 |
| S2 | R3/R4 无审批执行数 | 0 | **0**（审批门禁 3/3、令牌伪造 5/5） | 同上 | 达到决策层目标 |

P1 为单机决策微基准；P2/P3 包含指定检索环境与远程 embedding 调用条件。评审时应同时引用数据来源与样本口径。

## 3. RAG 检索性能与质量

### 3.1 运行配置

生产检索入口使用 `RetrievalConfig.defaults(topK)`，默认配置为：

- 向量、关键词和图谱三通道；
- RRF（Reciprocal Rank Fusion）融合，`k = 60`；
- 通道权重 V/K/G = **1.0 / 1.0 / 0.8**；
- 每通道候选数 `candidateN = 50`；
- 可按部署配置启用交叉重排。

正式部署使用 PostgreSQL；向量检索场景配置 pgvector 和 OpenAI-compatible embedding 服务。H2 内存路径用于不依赖 pgvector 的自动化测试，不作为向量检索性能数据源。

### 3.2 通道对照结果

数据源：`bench/rag/results/results.json`。

| 检索模式 | recall@5 | recall@10 | precision@5 | hit@5 | mrr@10 | ndcg@10 | map@10 | P95(ms) |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 纯向量 | 0.536 | 0.668 | 0.517 | 0.889 | 0.756 | 0.669 | 0.503 | 212.8 |
| 纯关键词 | 0.326 | 0.368 | 0.473 | 0.778 | 0.603 | 0.373 | 0.260 | 222.0 |
| 纯图谱 | 0.052 | 0.056 | 0.084 | 0.222 | 0.123 | 0.059 | 0.033 | 283.4 |
| 向量 + 关键词 | 0.601 | 0.758 | 0.556 | 0.944 | 0.783 | 0.729 | 0.570 | 207.6 |
| **向量 + 关键词 + 图谱** | **0.578** | **0.761** | **0.539** | **0.917** | **0.779** | **0.725** | **0.566** | **287.6** |

### 3.3 结果分析

- 三通道 recall@10 为 **0.761**，高于纯向量 **0.668**、纯关键词 **0.368** 和纯图谱 **0.056**；
- 三通道 P95 为 **287.6 ms**，低于 **800 ms** 目标；
- 二通道 recall@10 为 **0.758**，与三通道相近；其 recall@5、hit@5 和 P95 分别为 **0.601**、**0.944** 和 **207.6 ms**；
- 图谱通道主要提供关系解释和多跳证据。三通道相对二通道的质量与时延变化应结合业务对关系证据的需求评估；
- P95 包含远程 embedding API 网络往返，部署验收应在目标网络环境复测。

## 4. 安全决策性能

### 4.1 整体决策延迟

测试类：`AgentSafetyBenchmarkIT`；采集日期：2026-08-15；样本数：32。

| 指标 | 观测值 |
|---|---:|
| 均值 | **0.68 ms** |
| P50 | **0.41 ms** |
| P95 | **1.79 ms** |

同机多次执行的均值观测为 **0.61 / 0.69 / 0.68 ms**，P95 为 **1.70 / 1.64 / 1.79 ms**。该结果表明确定性护栏处于亚毫秒到毫秒量级；具体数值受运行负载影响。

### 4.2 分层治理对照

| 对照层级 | A0 基线 | A1 +审批门禁 | A2 +硬底线 | A3 +意图护栏 | A4 +令牌绑定 |
|---|---:|---:|---:|---:|---:|
| 决策延迟均值(ms) | 0.00 | 0.13 | 0.15 | 0.18 | 0.15 |
| 恶意拦截率 | 0.0% | 5.0% | 70.0% | 100.0% | 100.0% |

A0/A1 为评测对照层级；A2–A4对应生产安全链路的逐层组成。各层延迟差异处于微基准波动范围，主要用于确认完整治理链的总体开销量级。

### 4.3 安全硬指标

| 指标 | 结果 | 样本口径 |
|---|---:|---|
| 恶意意图拦截率 | **100%** | 20/20 |
| Prompt 注入/禁止动作 | **100%** | 8/8 |
| 关闭 Native Guard/审计 | **100%** | 6/6 |
| 意图不一致 | **100%** | 6/6 |
| R3/R4 无审批执行数 | **0** | 审批门禁 3/3 |
| 令牌伪造接受数 | **0** | 伪造拒绝 5/5 |

审批令牌采用 **SM2-with-SM3**，签名覆盖 17 个字段，执行侧对 13 个身份字段复判。审批决策权限为 `agent:approve`。

## 5. 测试环境与方法

### 5.1 安全决策基准

| 项 | 配置 |
|---|---|
| 运行环境 | JDK 17、Maven、JUnit |
| 数据库 | H2 内存数据库，PostgreSQL 兼容模式 |
| Flyway | 默认 V1–V12，现行核心表约 61 张 |
| 样本 | 恶意 20、良性 6、风险升级 3、审批门禁 3、令牌伪造 5 |
| 外部依赖 | 不依赖 LLM、Host Agent 和网络 |
| 复现命令 | `cd services/backend && mvn -B verify -Dbench.regenerate=true` |

规则管线为确定性实现，同一代码、配置和输入对应同一分类结果；延迟指标仍受主机负载影响。

### 5.2 RAG 检索基准

| 项 | 配置 |
|---|---|
| 语料 | 官方麒麟文档 17 篇，311 个 chunk |
| 知识图谱 | 221 个节点、135 条边 |
| 查询集 | 43 条：37 条正样本、6 条负样本 |
| 计分样本 | 36 条有效正样本 |
| 相关性标注 | 按 `goldDocs` 与 `goldKeyword` 自动派生 |
| 检索依赖 | Elasticsearch、远程 embedding、图谱抽取模型 |
| 时延口径 | 包含远程 embedding API 网络往返 |

该组结果适用于上述语料、标注规则和服务配置。图谱召回但不含 `goldKeyword` 的片段不计入 gold，因此跨通道比较应结合标注规则解释。

### 5.3 条件化复测要求

| 测试路径 | 启用条件 | 结果用途 |
|---|---|---|
| 安全门禁/架构对照 | JDK 17 + Maven | 决策准确率与微基准延迟 |
| RAG 检索 | `RAG_BENCH=1`、Elasticsearch、embedding/LLM 配置 | 检索质量与时延 |
| PostgreSQL/pgvector | `POSTGRES_IT_JDBC_URL=<jdbc url>` | 正式数据库与向量扩展集成 |
| 银河麒麟真机 | V11（aarch64）节点与控制面 | 工具执行、审批、审计链路验收 |

## 6. 适用范围与结果解释

### 6.1 安全指标

安全百分比基于封闭自动化用例集。20 条恶意样本中，14 条覆盖硬底线关键词，6 条覆盖意图不一致场景；两组共同用于验证规则匹配与意图对齐能力。扩展到其他攻击表达时，应增加对应样本并沿用相同判定规则。

### 6.2 RAG 指标

- 三通道与二通道 recall@10 相差 **0.003**，应视为该样本集下的接近结果；
- 标注规则基于文档与关键词自动派生，适用于当前麒麟运维语料；
- P95 包含外部 API 网络时间，跨环境对比须保持服务与网络条件一致；
- 图谱通道的评审重点包括关系证据和多跳解释，不仅限于单项召回率。

### 6.3 真机指标

银河麒麟 V11（aarch64）实机用于执行链路验收。端到端耗时、SSE 事件到达时延、大屏轮询刷新、并发与恢复类指标应从同一轮真机日志采集，并记录主机规格、网络条件、样本数与时间窗口。

## 7. 结论

| 指标域 | 结果 | 适用条件 |
|---|---|---|
| 安全决策延迟 | 均值 **0.68 ms**、P95 **1.79 ms** | 2026-08-15 单机、32 次决策评估 |
| 安全硬指标 | 恶意拦截 **100%（20/20）**；R3/R4 无审批执行数 **0** | 自动化决策用例集 |
| RAG 三通道 | recall@10 **0.761**、P95 **287.6 ms** | 36 条有效正样本及指定外部服务环境 |
| 总体结论 | 在所列测试环境与样本范围内，安全决策开销处于亚毫秒到毫秒量级，安全硬指标达到判定目标，三通道 RAG 指标达到设定时延目标 | 引用结果时同步保留环境、样本数与数据来源 |

后续可在统一的银河麒麟 V11（aarch64）验收脚本中持续沉淀端到端时延、SSE 到达时延、并发和恢复指标，形成跨版本可比的真机性能序列。
