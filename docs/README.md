每份技术文档提供 Markdown 和 Word 两种格式。修改 Markdown 后可用 `bash scripts/export-submission-docx.sh` 同步 Word。运行 `python3 scripts/verify-doc-consistency.py` 检查代码引用，运行 `bash scripts/export-submission-docx.sh --check` 检查 Word 正文。

项目用例和指标计划见[项目材料与评估清单](麒麟安全智能运维Agent_项目材料与评估清单.xlsx)。可观测组件的安装与验证见 [部署目录说明](../deploy/README.md)。评估数据和生成结果位于 [bench](../bench/)。
