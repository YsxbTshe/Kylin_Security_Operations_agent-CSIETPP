## 一、系统安装

![安装-选择语言](guide-images/01-安装-选择语言.png)  ![安装-选择时区](guide-images/01-安装-选择时区.png)

### 最低配置与推荐配置

| 版本形态 | 最小内存 | 推荐内存 | 最小硬盘空间 | 推荐硬盘空间 |
|---------|---------|---------|------------|------------|
| 桌面系统 | 4GB | 8GB及以上 | 60GB | 80GB及以上 |

### 安装准备

1. 准备安装光盘或 U 盘启动器
2. 检查硬件兼容性 — openKylin 与近年来生产的大多数硬件兼容
3. **备份数据** — 安装前务必将重要数据备份到其他存储设备
4. 了解硬盘分区 — 一块硬盘最多有四个主分区，需要多于四个分区需设为逻辑分区

### 安装引导

1. 将安装介质放入电脑，重启后根据固件提示进入启动项选择界面
2. 选择"Try without installing"可试用系统，双击"安装 openKylin"开始安装
3. **选择语言** — 选择系统安装语言
4. **选择时区** — 默认为北京时区，可在地图中点选城市切换
5. **创建用户** — 输入用户名、设置密码，可勾选"开机自动登录"
6. **选择安装方式**

#### 全盘安装

选择"全盘安装"，选中目标盘符，系统自动分区，勾选"格式化整个磁盘"，点击"开始安装"。安装完成后点击"现在重启"，取出安装介质后按 Enter 键即可进入系统。

#### 自定义安装

- 选择"自定义安装"后可自行设计各分区大小
- 先创建 `/boot` 分区（必须是主分区的第一个分区）
- 继续创建根分区（`/`）、`backup`、`tmp` 等分区
- 分区类型选"主分区"，位置选"剩余空间头部"，文件系统选"ext4"
- 支持添加、修改、删除分区操作

## 二、桌面环境

![桌面-默认界面](guide-images/02-桌面-默认界面.png)  ![桌面-小窗口模式](guide-images/02-桌面-小窗口模式.png)

### 登录

开机后进入登录界面，选择已创建的用户，输入密码即可登录桌面。密码输入支持隐藏/显示切换。

### 桌面组成

初始桌面由**图标**、**任务栏**、**桌面背景**组成，默认放置三个图标：
- **计算机** — 显示连接到本机的驱动器和硬件
- **回收站** — 显示被删除到回收站的文件
- **主文件夹** — 显示个人主目录

### 桌面右键菜单

| 选项 | 说明 |
|------|------|
| 在新窗口中打开 | 在新窗口打开当前指定的文件或目录 |
| 全选 | 全选当前目录的文件 |
| 新建 | 可新建文件夹、空文本、WPS 文件 |
| 视图类型 | 提供四种：小图标、中图标、大图标、超大图标 |
| 排列方式 | 多种排列图标方式 |
| 刷新 | 刷新界面 |
| 打开终端 | 打开终端软件 |
| 设置背景 | 快捷打开个性化背景设置 |

### 电源管理

| 功能 | 说明 |
|------|------|
| **关机** | 退出登录并关闭计算机 |
| **重启** | 退出登录并重启计算机 |
| **注销** | 清除并登出当前用户，返回登录位置 |
| **锁屏** | 暂时离开时使用，输入密码可重新进入（快捷键 Super+L） |
| **睡眠** | 切断除内存外其他配件电源，可快速恢复工作状态 |
| **休眠** | 将内存数据转存到硬盘后切断所有设备供电，需通过电源键唤醒 |

### 文件及文件夹（桌面操作）

桌面右键 → **新建** → 选择新建文件类型或文件夹。桌面文件/文件夹支持以下操作：

| 操作 | 说明 |
|------|------|
| 打开 | 打开文件/文件夹 |
| 打开方式 | 选择默认或其它关联应用程序 |
| 复制/剪切 | 复制或移动文件 |
| 重命名 | 重命名文件或文件夹 |
| 删除到回收站 | 删除文件到回收站 |
| 创建链接 | 创建快捷方式 |
| 属性 | 查看基本信息、共享方式及权限 |

### 图标排列和大小

桌面右键选择 **"视图类型"** 调整图标大小（小/中/大/超大）。图标可拖拽到指定位置。排序方式支持：名称、大小、类型、修改时间。

### 任务栏

位于桌面底部，默认包含：
- 开始菜单、显示任务视图、文件管理器、Firefox 浏览器
- 键盘（切换输入法）、麒麟天气、网络设置、通知中心、声音、夜间模式

### 开始菜单

系统使用的"起点"，支持**全屏**和**小窗口**两种模式切换。可在搜索框输入应用名称或关键字快速定位应用。支持在开始菜单中右键卸载应用。

### 侧边栏

包含三个模块：
- **通知中心** — 显示系统通知，可设置允许通知的应用
- **剪切板** — 显示近期复制的文字或截图
- **小插件** — 闹钟、便签贴、服务与支持等

打开方式：点击任务栏右下角侧边栏图标或快捷键 **Win+A**

### 显示任务视图

通过任务栏"显示任务视图"图标打开，可切换多个桌面，对窗口进行分组管理。

### 日历

点击桌面右下角时间与日期弹出日历界面，支持：
- 月份/年份切换
- 今天跳转
- 黄历宜/忌折叠查看

### 触控交互

若设备支持触控功能，可使用多种手势操作：

| 手势 | 操作 |
|------|------|
| 单指单击 | 选择对象、打开菜单 |
| 单指双击 | 打开应用、文件夹 |
| 单指长按 | 显示右键菜单 |
| 单指滑动 | 滚动列表、切换页面 |
| 双指捏合 | 缩放页面 |
| 单指从屏幕底部向上滑 | 打开多任务视图 |
| 四指左右滑动 | 切换应用窗口 |
| 四指向下滑 | 进入全局搜索 |
| 单指屏幕右侧滑入 | 呼出侧边栏 |

### 输入法

系统集成 **Fcitx 输入法框架**（小企鹅输入法），支持五笔、拼音、二笔、区位、仓颉等输入模块。并默认预装搜狗输入法，为用户提供稳定、流畅的中文输入体验

配置方式：
- 任务栏输入法图标右键 → **配置**
- 开始菜单 → **设置** → **键盘** → **输入法设置**

支持添加/删除输入法、设置输入法顺序、全局配置（切换快捷键、默认状态等）

## 三、系统设置（控制中心）

![设置-主界面](guide-images/03-设置-主界面.png)  ![设置-账户](guide-images/03-设置-账户.png)

设置界面提供对操作系统常用配置项的管理，主要模块如下：

### 1. 账户

- **账户信息** — 管理用户（创建、删除、修改用户信息）
  - 更改用户头像、修改密码、更改账户类型（标准用户/管理员用户）
  - 编辑用户组、添加新用户（支持设置密码安全问题）
  - 双因子认证：支持 OTP 动态口令与安全密钥
- **登录选项** — 配置生物识别（指纹、人脸等）登录开关

### 2. 系统

- **显示器** — 分辨率、方向、刷新率、缩放（根据分辨率自动适配最大缩放比例）、护眼模式、色温、夜间模式
- **声音** — 输出设备选择、音量调节、音量增强、声道平衡、输入设备选择、智能降噪、系统音效开关、音效主题
- **电源** — 通用功能、电源计划（性能模式）、电池节能计划
- **通知** — 按应用设置通知开关
- **关于** — 系统版本、设备规格、用户信息、隐私协议
- **维护模式** — 不可变系统的可写模式开关，支持水印样式设置

### 3. 设备

- **蓝牙** — 开关、修改名称、设备发现与配对、文件传输、音频组合设备
- **打印机** — 打印机设置入口
- **鼠标** — 主按键、双击速度、滚轮速度、指针速度/大小、光标闪烁
- **触控板** — 插入鼠标时开关、打字时禁用、轻触点击、滚动方式、交互手势（三指/四指）
- **触摸屏** — 触控手势交互、触摸校准
- **键盘** — 按键重复设置、虚拟键盘、输入法配置
- **快捷键** — 查看系统应用快捷键、自定义快捷键、恢复默认

### 4. 网络

- **有线网络** — 显示、连接或断开
- **无线局域网** — 显示、连接或断开
- **代理** — 系统代理（自动/手动）、APT 代理
- **VPN** — 打开外部 VPN 设置程序
- **移动热点** — 以本机作为无线网络提供方

### 5. 个性化

- **背景** — 颜色或图片两种形式，六种显示方式（填充、平铺、居中、拉伸、适应、跨区）
- **主题** — 主题模式、窗口外观、图标/光标主题、窗口特效
- **锁屏** — 选择登录界面背景图片
- **屏保** — 设置屏保程序、等待时间
- **字体** — 字体大小、等宽设置、安装/卸载/搜索字体
- **任务栏** — 图标合并、大小、位置、自动隐藏、锁定

### 6. 时间语言

- **时间和日期** — 自动同步 NTP 时间、手动设置、更改时区
- **区域语言** — 语言格式、系统语言（推荐简体中文）、添加备选语言

### 7. 更新

- 检测系统可用更新
- 支持在线升级和离线升级
- 自动下载更新设置（周期、时间段）
- 回退到上一个版本
- 更新历史查看

### 8. 备份

创建系统/数据备份、还原历史备份。会打开备份还原工具进行操作。


### 9. 应用

- **开机启动** — 添加/查看开机自启动应用
- **默认应用** — 修改各类文件的默认打开应用

### 11. 搜索

全局搜索设置（提高搜索效率）。

### 12. 通用

- **系统启动** — Grub 验证开关、Grub 启动延时、默认启动项
- **辅助功能** — 放大镜、色彩滤镜
- **AI 模块管理** — AI 子系统简介、模型配置（新增/删除/编辑/启用/禁用/优先级）

## 四、文件管理器

![文件管理器-主界面](guide-images/04-文件管理器-主界面.png)  ![文件管理器-智能空间](guide-images/04-文件管理器-智能空间.png)

### 概述

文件浏览器支持分类查看文件和文件夹，进行常用操作（复制、粘贴、重命名、删除等）。

### 基本要点

- **文件名**：最长 255 个字符，以 "." 为首字母时默认隐藏，不能含 "/"
- **路径**：绝对路径（如 /home/kylin/test）和相对路径（取决于当前目录）
- **文件类型**：普通文件、目录文件、设备文件（字符/块）、符号链接

### 窗口组成

六个部分：工具栏和地址栏、文件夹标签预览区、侧边栏、窗口区、状态栏、预览窗口

### 主要功能

**视图模式**：图标视图、列表视图、计算机视图

**排序方式**：按名称、修改日期、类型、大小、升序/降序、标记筛选

**搜索和筛选**：搜索框输入关键字，支持高级筛选（名称、类型、大小、修改时间）

**常用操作**：
- 复制：Ctrl+C / Ctrl+V 或拖拽（跨设备自动复制，同设备需按 Ctrl）
- 移动：Ctrl+X / Ctrl+V
- 删除：Delete 到回收站，Shift+Delete 永久删除
- 重命名：F2 或右键，Ctrl+Z 可撤销

**格式化和卸载设备**：侧边栏右键移动设备，支持格式化（NTFS/Ext4/VFAT）、卸载、弹出、重命名

**磁盘加密**：支持加密磁盘、继续加密、锁定/解锁、更改密码、取消加密（支持数据盘和系统盘）

**访问网络**：通过共享选项在局域网共享文件，支持网上邻居访问

### 智能空间

借助 AI 子系统能力，实现文件按标签分类、摘要预览、语义内容搜索。

**空间管理**：创建空间（筛选条件新建/搜索新建）、删除、重命名、编辑条件动态更新

**空间内文件操作**：
- 手动添加 / 拖拽添加文件
- 文件另存为副本
- 移动文件至其他空间
- 概要抽取（20~50 字摘要）
- 智能标签（自动生成、动态更新）
- 智能排序（按使用频率+最近访问时间）
- 按添加方式排序（手动/自动）

### 快捷键一览

| 快捷键 | 功能 |
|--------|------|
| Ctrl+C / Ctrl+X / Ctrl+V | 复制/剪切/粘贴 |
| Delete | 删除到回收站 |
| Shift+Delete | 永久删除 |
| Ctrl+Z | 撤销 |
| Ctrl+A | 全选 |
| F2 / Alt+E | 重命名 |
| Ctrl+H | 显示/隐藏隐藏文件 |
| Ctrl+T | 新增标签页 |
| F11 | 最大化/还原窗口 |
| Alt+↑ | 返回上一级目录 |

## 五、系统监视器

![系统监视器-主界面](guide-images/05-系统监视器-主界面.png)  ![系统监视器-资源](guide-images/05-系统监视器-资源.png)

### 概述

监控系统进程、系统资源和文件系统的专业应用。

### 进程

显示所有已启动进程的核心信息：进程号、名称、用户、CPU 占用率、内存、优先级、磁盘 IO 速率、网络流量等。支持强制结束、结束进程、设置优先级。

### 服务

显示所有服务列表：名称、加载状态、运行状态、描述、进程号、启动方式。支持启动、停止、重新启动、设置启动方式。

### 资源

- **处理器历史** — 动态折线图，显示实时 CPU 占用率，支持切换显示逻辑处理器
- **内存和交换空间历史** — 动态显示实时占用量和总量
- **网络历史** — 实时接收/发送速率
- **磁盘历史** — 磁盘型号、容量、读写速度

### 磁盘

已挂载分区列表：挂载路径、类型、容量、可用空间、剩余空间。

## 七、终端

### 概述

麒麟系统的命令行操作媒介，提供图形化界面下的字符系统窗口。

### 打开方式

- 开始菜单 → **终端**
- 桌面空白处右键 → **打开终端**
- 文件管理器目录中右键 → **打开终端**
- 任务栏搜索 → **终端**

### 基本操作

终端窗口格式示例：`kylin@kylin-pc:/opt$`
- `kylin` — 用户名
- `kylin-pc` — 计算机名
- `/opt` — 当前路径

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+Alt+T | 打开新终端窗口 |
| Ctrl+Shift+T | 打开新标签页 |
| Ctrl+D | 关闭当前窗口/标签页 |
| F11 | 全屏/退出全屏 |

### 高级设置

- **窗口标题** — 终端 → 设置标题

## 九、安装器

![安装器-日间模式](guide-images/09-安装器-日间模式.png)

### 概述

图形化软件包管理功能，支持 deb、ok、oab 等多种包格式的安装与卸载。

### 软件安装

三种方式：

1. 在开始菜单中打开安装器，点击"添加"选择软件包 → 点击"安装"
2. 双击 deb 包，弹窗安装器点击"一键安装"
3. 终端输入 `kylin-installer + 包名`，如：
   `kylin-installer browser360-cn-stable_10.6.1022.22-1_amd64.deb`

支持**批量安装**，安装器自动识别在系统或兼容环境中安装。

### 软件卸载

- 开始菜单中右键应用选择"卸载"
- 终端输入：`kylin-uninstaller + desktop 文件路径`

注：应用正在运行时不允许卸载；不允许同时卸载两个及以上软件。

### 常见问题

- **.exe 软件**：V10 SP1 2303 版本在 X86/ARM 架构下可通过 KWRE 兼容环境运行
- **离线安装**：`sudo dpkg -i 软件包名`
- **在线安装**：通过软件商店
- **更新软件源**：`sudo apt update`
- **安装依赖缺失**：`sudo apt-get install xxx（依赖包名）`
- **批量安装**：文件夹中执行 `sudo dpkg -i *`

## 十、备份还原

![备份还原-系统备份](guide-images/10-备份还原-系统备份.png)  ![备份还原-位置选择](guide-images/10-备份还原-位置选择.png)

### 概述

支持系统备份/还原、数据备份/还原。支持新建备份点、增量备份、Grub 备份还原。

### 系统备份

将除 /backup、/media、/run、/proc 等目录外的整个文件系统备份。可选择备份到本地备份分区、移动设备或本机非备份分区。

流程：选择位置 → 环境检测 → 定义备份点名称 → 开始备份

### 系统还原

选择备份点 → 环境检测 → 开始还原。还原成功后系统自动重启。

### 数据备份与数据还原

对家目录 `/home/xxx`、`/data` 或 `/data/usershare` 目录下的数据进行备份。支持数据增量备份（在某个备份点上更新）。

### Ghost 镜像

- **创建 Ghost 镜像**：基于本地系统备份生成 `.kyimg` 镜像文件（格式：主机名+体系架构+备份名称.kyimg）
- **安装 Ghost 镜像**：进入 Live 系统，加载 U 盘中的镜像文件进行安装

### Grub 备份还原

开机在 Grub 菜单中选择系统备份还原模式（仅支持安装时有备份分区的机器）。

### 常见问题

- 安装系统时必须选中"创建备份还原分区"才能使用备份还原
- 备份分区空间不足时可使用移动设备备份
