# 磁盘告警排查

适用场景：监控上报 Kylin 服务器根分区或数据分区使用率超过 85% 的告警。

## 排查步骤

1. 运行 `scripts/analyze.sh` 收集只读诊断信息（分区使用率、大目录 Top 10、inode 使用率）。
2. 对照 `references/runbook.md` 判断占用来源属于哪一类（日志堆积 / 软件包缓存 / 业务数据）。
3. 仅输出结论与建议，不执行任何删除动作；清理属于写操作，需另行走审批流程。

## 输出要求

- 列出使用率超过 85% 的挂载点及其 Top 10 大目录。
- 标注每个大目录是否属于可安全清理的缓存类目录。
- 给出下一步建议（观察 / 申请清理审批 / 扩容评估）。
