# 磁盘告警 Runbook（麒麟服务器）

## 占用来源分类

| 类别 | 典型路径 | 可否清理 |
| --- | --- | --- |
| 系统日志堆积 | /var/log/journal、/var/log/*.log.* | 日志轮转策略调整，需审批 |
| 软件包缓存 | /var/cache/dnf、/var/cache/yum | 可清理缓存，需审批 |
| Core dump | /var/lib/systemd/coredump | 确认无取证需求后清理，需审批 |
| 业务数据 | /var/lib/*、/data | 禁止直接清理，先评估归档 |
| 已删除未释放 | `lsof +L1` 可见 | 重启对应进程释放，需审批 |

## 判断口径

1. 使用率 85%~90%：输出观察建议，标注增长最快的目录。
2. 使用率 90%~95%：给出可清理项清单与预计释放量，提交清理审批。
3. 使用率 >95%：升级为紧急工单，同时给出扩容评估结论。

## 注意

- 本 runbook 全部步骤只读；任何删除、截断、重启动作必须走写操作审批。
- 不读取业务文件内容，只统计目录占用。
